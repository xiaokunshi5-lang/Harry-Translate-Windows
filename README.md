# 会议实时双向双屏同传系统（最初版 · 纯双通道）

基于 **阿里云百炼千问实时同传大模型（`qwen3.8-livetranslate-flash-realtime`）+ FastAPI + WebSocket** 搭建的极简双通道实时同传投屏系统。

本版本保留最纯粹的核心能力：**单麦克风拾音、中英双向并发翻译、双屏幕独立投送与同屏分栏监看**（不包含悬浮窗、术语库、多引擎切换等复杂扩展）。

## 🌟 核心功能

1. **中英双向独立大屏**
   - 🎤 **中译英大屏（`/en`）**：面向外宾。中文实时译为英语，英文自动直出。
   - 🇨🇳 **英译重大屏（`/zh`）**：面向中方。英文实时译为中文，中文自动直出。
2. **左右双栏监看屏（`/split`）**：在主控电脑上同时监看中译英与英译中双通道输出。
3. **双通道异步解耦**：麦克风采样与云端 WebSocket 推流队列隔离，单路重连不影响另一路正常翻译。
4. **Token 用量与费用实时统计**：`/api/stats` 实时展示输入/输出 Token 消耗及预估费用。

## ⚡ 快速启动（已完成环境配置后）

### macOS

- **方式一（推荐）**：打开桌面 **「最初版的同传」** 文件夹，双击 `启动同传系统.command`。
- **方式二（终端）**：
  ```bash
  cd ~/Desktop/最初版的同传 && ./start.sh
  ```

### Windows

在文件夹空白处右键打开 **终端 / PowerShell**，运行：

```powershell
.venv\Scripts\activate
python server.py
```

启动后在浏览器访问以下地址：

| 页面 | 访问地址 | 用途 |
| :--- | :--- | :--- |
| **主控面板** | <http://localhost:8000/> | 导航首页与通道入口 |
| **中译英大屏** | <http://localhost:8000/en> | 投屏给外宾（建议全屏） |
| **英译重大屏** | <http://localhost:8000/zh> | 投屏给中方（建议全屏） |
| **双栏监看屏** | <http://localhost:8000/split> | 主控电脑同屏对照监看 |

## 🔑 更换 API Key

- **macOS 双击**：运行 `切换API_Key.command`，按提示粘贴新的 `sk-xxxx`。
- **命令行（Mac / Windows 通用）**：
  ```bash
  python switch_key.py "你的新sk-xxxx"
  ```
  或直接编辑目录中的 `.env` 文件，修改 `DASHSCOPE_API_KEY=` 后的内容并保存。

> **安全提示**：服务默认监听 `0.0.0.0`，可被同一局域网内设备访问。若在公共 Wi-Fi 或不可信网络中使用，请把 `server.py` 最后一行的 `host="0.0.0.0"` 改成 `host="127.0.0.1"`，确保只有本机能访问服务。
